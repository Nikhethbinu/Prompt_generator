# 🚀 AI Prompt Generator 

A high-performance **AI Prompt Generator** built with **React, Tailwind CSS, Node.js, and Groq API**.
Designed to generate **context-aware, high-quality prompts** for developers, creators, and learners.

---

## ✨ Overview

This project transforms simple user input into **optimized AI prompts** using LLMs powered by Groq.

It demonstrates:

* 🔗 Frontend–Backend integration
* ⚡ Real-time AI inference
* 🎯 Prompt engineering techniques
* 🎨 Modern responsive UI design

---

## 🔥 Key Features

* ⚡ **Ultra-fast AI responses** using Groq inference
* 🧠 **Context-aware prompt generation**
* 🗂️ Multi-category support:

  * Coding
  * Writing
  * Image Generation
  * Study
* 🎯 Clean and intuitive UI (Tailwind CSS)
* 📋 One-click copy to clipboard
* 🧾 Auto-resizing input box (dynamic UX)
* 🎬 Smooth UI animations (hover, zoom, transitions)
* 🔙 Seamless page navigation

---

## 🧱 Architecture

```id="8wcmj6"
Frontend (React + Tailwind)
        ↓

        ↓
Groq API (LLM Inference)
        ↓
AI Generated Prompt
```
